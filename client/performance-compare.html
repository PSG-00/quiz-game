LOD 비교 · 기존 LOD 기본 적용

기본 게임은 A(기존 LOD)로 복원했습니다. 실제 폰에서 B·C의 성능 이득이 확인되지 않아 두 버전은 실험용으로만 보존합니다.

A · 기존 LOD (현재 기본)B · 추가 최적화 실험 (채택 보류)C · 고화질 실험 (채택 보류)C는 모바일 최대 DPR 2→2.25, 픽셀 예산 160만→200만입니다. 기기 DPR이 2 이하라면 해상도 차이가 없을 수 있습니다. 먼저 A/B를 비교하고 C의 선명도와 FPS를 확인하세요. B/C 측정 메뉴에서는 5분 안정성도 선택할 수 있습니다. CPU / GPU 진단의 %는 60FPS 프레임 예산 대비이며, 기기 전체 사용률이 아닙니다. 순수 FPS 비교는 진단 측정을 끄고 진행하세요.

채택: WebGL + LOD · 실기기에서 폰 50~52 FPS, 노트북 약 110 FPS. 기본 게임에 적용했습니다.

같은 기기·브라우저에서 한 번에 한 화면만 열고 비교하세요. 자동 비교는 실제 방에 입장하지 않습니다.
