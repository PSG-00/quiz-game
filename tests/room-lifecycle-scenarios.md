# 방장 승계·방 종료·내 퀴즈 보관 테스트

## 현재 구현된 기준

- 퀴즈 저장은 서버의 개인 보관함에 미완성 초안까지 저장한다. 같은 브라우저의 비밀 키로 소유자를 구분한다.
- 실제 게임 방은 메모리에 유지하고 마지막 사람이 퇴장하거나 연결을 끊으면 즉시 종료한다. 저장 퀴즈는 그대로 남는다.
- 방장 퇴장 시 남은 사람 중 가장 먼저 입장한 사람에게 승계한다. 유령·관전자도 가능하다.
- 진행 중 승계는 문제·마감 시각·답안·위치·게임 ID를 초기화하지 않는다. 원래 방장이 재입장해도 승계된 권한을 회수하지 않는다.
- 방장 운영 권한과 원작자의 저장 퀴즈 소유권을 구분한다. 봇과 삭제 방 복원은 없다.

| 선택되지 않은 문제 목록 확인 | 모든 문제에 테두리, 선택된 문제만 강조 | 브라우저 |

## 후속 검증이 필요한 예외

- A/B/C의 거의 동시 퇴장과 접속 경합에서 현재 방장이 한 명인지.
- 객관식·부활전·추첨 단계의 방장 퇴장 후 제출값과 진행이 유지되는지.
- 100명 실제 접속, 다중 탭, 불안정한 모바일 네트워크.

이전 제안에 포함한 30초 재접속 유예·접속 복구는 현재 구현하지 않는다. 마지막 연결이 끊기면 방이 종료되는 것이 현재 동작이다.
