# PC·모바일 공통 성능 우선 렌더링

2026-10-26 사용자 요청: PC에서도 모바일처럼 그림자와 해상도 보정 후처리를 제거한다.

- PC 전용 FXAA의 별도 렌더 타깃·전체 화면 패스를 없애고 `renderer.render(scene,camera)`로 직접 그린다. `sceneAntialias.js`, `vendor/FXAAShader.js`와 HTML 로딩도 삭제한다.
- 하드웨어 안티앨리어싱은 기존처럼 끈다. 실시간 그림자 맵과 개인/원격 캐릭터의 원형 접지 그림자도 끈다. 기본 조명·기존 아바타·LOD·GPU 인스턴싱·내 캐릭터 식별 링은 유지한다.
- 기기 분기 없이 DPR 최대 2, 약 **160만 렌더 픽셀 상한**을 적용한다. 큰 PC 화면은 내부 렌더 해상도가 낮아질 수 있으며 화질보다 성능을 우선한 선택이다. 창 크기 변경 시에도 다시 계산한다.
- 내 이동·카메라·몸체는 기존 프레임 루프로 갱신한다. 닉네임·말풍선·상태 배지 위치도 매 렌더 프레임 갱신한다. 이름 크기는 이름/화면 크기 변경 시, 말풍선 크기는 내용/화면 크기/상단·측면 배치 변경 시 캐시를 갱신한다. 측면 가용 폭은 16px 단위로 묶어 이동 중 반복 측정을 줄인다. 개별 아바타 포즈의 보조 경로는 약 30Hz로 제한한다. 인스턴싱 동작 보간은 유지한다.
- 관전자는 아바타를 그리지 않으며, 선택한 생존자의 공개 좌표로 로컬 카메라만 따라간다. 영상 스트리밍·추가 카메라 통신·타인의 비공개 답안 공유는 하지 않는다. PC는 기존 전체 무대 시야, 세로 화면은 선택한 대상의 좌우 이동을 따라간다.

검증은 `tests/render-budget.test.cjs`, 전체 자동 테스트, 실제 Chromium의 PC/모바일 화면에서 수행한다. `scripts/audit-client-judgement.cjs`가 그림자 맵 OFF·AA OFF·FXAA 미로드·접지 그림자 드로우 0·렌더 픽셀 예산을 검사한다. 정상 이동·재접속·관전 대상 전환도 함께 검증한다.

이 결과는 실제 노트북/폰에서의 FPS 상승 수치를 측정한 것이 아니다. 사용 기기의 FPS와 체감은 적용 후 별도로 비교해야 한다.

표시 위치 회귀 검사: PC 및 390px 모바일 화면 Chromium에서 실제 렌더 24프레임 모두 원격 이름 위치가 변경됨을 확인한다. 해당 이동 구간의 이름/채팅 크기 측정은 0회, 채팅 내용 변경 시 폭·높이 측정 2회였다. 전체 프레임 시간이나 실기기 FPS 개선 수치를 의미하지 않는다.

## 사회자 무대 배경판

RESCENE / WITH RE:MINE 글자와 파스텔 꽃 무늬를 시작 시 한 번 1024×512 캔버스에 그린다. 12삼각형짜리 얇은 상자 하나에 불투명 텍스처 아틀라스를 입히고 재질 그룹을 합쳐 드로우콜 1회로 렌더링한다. 조명/그림자/투명 정렬/프레임별 텍스처 갱신/추가 서버 통신은 없다. 원본 RGBA 텍스처는 2MiB이며 기본 밉맵 포함 GPU 텍스처는 약 2.67MiB(캔버스 메모리 별도)다. 일반 이미지 장식도 GPU 렌더 비용이 0이 되는 것은 아니다.

기존 160만 픽셀 상한과 DPR 최대 2는 유지했다. PC·모바일 화면 Chromium에서 배경판 표시 전후 renderer.info.render를 비교하여 추가 calls=1, triangles=12를 확인했다. 기존 답안·재접속·관전 브라우저 회귀 검사도 통과했다. 실기기 50명 FPS 비교는 수행하지 않았다.

### 승인된 멤버 이미지 적용

배경판을 12×3.8에서 24×7.6으로 키웠다. 승인된 크림/민트 RESCENE QUIZ 배너를 `client/assets/stage/rescene-quiz-members-v2.webp`(160,262바이트)에 저장하고, 사진이 가로로 늘어나지 않도록 원본 3:2 비율로 배경판 중앙에 맞춘다. 넓은 좌우는 같은 크림색으로 연장한다. 2048×1024 아틀라스에 최초 로딩 때만 합성하며 삼각형 12개/드로우콜 1개는 유지한다. RGBA 기본 텍스처 8MiB, 밉맵 포함 약 10.67MiB로 기존보다 텍스처 메모리는 증가한다. 화면 렌더 해상도는 변경하지 않는다. PC·모바일 브라우저에서 이미지 로딩 완료와 렌더 증가량, 기존 게임 동작을 검증했다.

### 이미지 외곽선과 판 끝 정렬 (현재)

24×7.6 판에 이미지를 중앙 배치하던 좌우 연장 영역과 덧그린 민트 선을 제거했다. 판 앞면 전체에 승인된 배너를 매핑하고 판 비율을 이미지와 같은 3:2로 맞춘다. 모바일/터치 또는 폭 680px 이하에서는 10.5×7, PC에서는 9.9×6.6이며 하단은 기존 무대 발판 위 0.6으로 맞춘다. 화면 크기/방향이 바뀌면 기존 판의 scale만 조정하며 추가 메시는 생성하지 않는다. 1024×1024 텍스처에 이미지 전체를 사용하고 3:2 앞면에서 원래 비율로 보이게 한다. 기본 RGBA 4MiB, 밉맵 포함 약 5.33MiB다.

PC·모바일 화면 Chromium에서 기기별 크기, 3:2 비율, 이미지 로드 완료, 드로우콜 1개/12삼각형 유지와 기존 답안·재접속·관전 동작을 검증했다. 외곽선 스크린샷은 artifacts/host-backdrop.png 및 host-backdrop-mobile.png에 저장한다.
