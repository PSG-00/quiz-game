# 참가 자격·재접속·판정 방어 — 2026-10-26

이 문서는 [초기 버그 점검](game-bug-checklist.md) 후 사용자가 확정한 정책과 실제 수정 결과다. 세션/대기실 수정은 `976139f`까지 운영 배포했다. 이후의 관전 전용 화면과 공통 렌더링 수정은 별도 후속 작업이며 아래 검증은 로컬 격리 서버 기준이다.

복귀 정보는 탭의 `sessionStorage`에 보관하므로 같은 탭의 자동 재연결·새로고침을 지원한다. 저장소 삭제·새 기기·복귀 정보 없는 새 탭은 자동 복귀 대상이 아니다. 서버 재시작은 메모리의 방·세션을 종료하며 저장 퀴즈와 별개다. 네트워크가 조용히 끊어진 경우 감지는 기존 ping/pong 주기에 영향을 받으며, 실제 단말의 망 단절 시각부터 정확히 30초를 재는 것은 아니다.

## 정원과 서버 부하

- 총정원은 **50명**. 생존자·기존 참가자 유령·관전자·복귀 예약을 모두 한 자리씩 계산한다.
- 참가자 객체를 삭제하지 않고 `connected=false`로 보존하므로, 예약 자리가 신규 입장으로 소비되지 않는다. 복귀는 객체를 추가하지 않는다.
- 방 목록 `playerCount`는 예약 포함 사용 자리다. `reservedCount`도 전송하고 목록에 ‘복귀 예약 N’을 표시한다.
- 별도 접속자·관전자 수 필드를 보내며 관전자는 생존·유령 집계에서 제외한다.
- 서버 전체 WebSocket 상한: 기본 **500개**, `OX_MAX_CONNECTIONS`로 조정(최소 50). 로비 연결과 테스트 봇 소켓도 포함한다. 상한 초과 시 1013으로 새 연결을 닫는다. 이는 성능 측정으로 보증한 안전 동접 수가 아니라 무제한 접속을 막는 기본 상한이다.
- 각 연결 전체 요청: 초당 60, 초기 여유 120. MOVE는 초당 30/여유 10, 채팅은 초당 1/여유 3, 답안 제출은 초당 5/여유 10, 수정 중 알림도 별도 초당 5/여유 10이다. 키 입력 알림이 답안 제출의 여유량을 소모하지 않는다.
- 이동은 서버 경계·유한값 검사에 더해 거리 예산을 검사한다. 정상 속도 7에 대해 초당 8.5, 최대 누적 여유 거리 2를 허용하고 과도한 점프는 거절·서버 좌표로 보정한다. 서버 내부 NPC 제어는 신뢰된 직접 호출로 별도 처리한다.
- 공개 48봇 방도 보존한다. 접속한 사람이 없으면 예약만 남아 있어도 봇 이동을 멈춘다.

이 제한이 Cloudflare 429나 모든 종류의 외부 부하를 방지한다고 보장하지 않는다. 클라이언트별 제한은 방화벽·계정별 악성 접속 방어를 대체하지 않으며 서버를 여러 프로세스로 확장하면 방/예약을 공유하는 설계가 별도로 필요하다.

## 판정과 지연 요청

- 판정은 항상 서버 수신 상태를 기준으로 한다. 마감 후 도착한 이동·답안을 소급 적용하지 않는다.
- OX·소수결·4구역은 `client/arenaRules.js`의 동일한 소수 둘째 자리 반올림과 경계 함수를 사용한다. `x=-0.001`은 양쪽 모두 `x=0 → X`로 판단한다.
- 각 게임의 `gameId`, **매 문제 개방의 고유 `roundId`**를 답안·수정 중 요청·답안 ACK에 포함한다. 같은 문제 번호를 재도전해도 새 roundId를 발급한다.
- 서버는 식별자가 없거나 다른 답안·수정 요청을 무시한다. 브라우저도 이전 문제 ACK를 무시한다. 구버전 클라이언트는 새로고침해야 한다.
- 통신 지연 때문에 아직 도착하지 않은 이동의 예측 표시와 서버 판정이 다를 수 있다는 점은 합의한 서버 우선 정책으로 유지한다.

## 실행

- `npm test`: 전체 자동 테스트와 실제 연결 회귀 시험.
- `node scripts/audit-game-concurrency.cjs`: 격리 서버의 실제 연결 시험.
- 실제 유예 타이머까지: PowerShell `$env:AUDIT_REAL_GRACE='1'; $env:AUDIT_LABEL='session-final'; node scripts/audit-game-concurrency.cjs`.
- `node scripts/audit-client-judgement.cjs`: PC 브라우저 시험.
- 모바일 화면: `$env:AUDIT_PORT='3134'; $env:AUDIT_MOBILE='1'; node scripts/audit-client-judgement.cjs`.
- 시험 서버 제어는 fork IPC 전용이며 운영 HTTP API에는 연결하지 않는다. 저장 기능을 끄므로 운영/로컬 퀴즈 파일을 수정하지 않는다.
