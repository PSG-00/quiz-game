# 배포 도메인 테스트 방

PM2 production 설정의 `OX_PUBLIC_TEST_BOTS=48`로 서버 시작 시 **[테스트] 봇 48명 · 사람 2명** 방을 하나만 생성한다. 일반 방과 동일한 50명 정원이며 실제 사용자는 두 자리까지 입장한다. 봇이 남아 있으므로 사람이 모두 나가도 방을 유지하고 서버 재시작 후에는 새 방 ID로 하나를 다시 생성한다.

첫 번째 실제 입장자가 방장이며 퇴장하면 다음 실제 사용자에게 넘긴다. 실제 사용자가 없으면 봇을 임시 방장으로 두고 다음 실제 입장자가 권한을 받는다. 클라이언트가 봇 ID 집합을 설정하거나 이 예외를 일반 방에 적용하는 경로는 없다.

문제는 기존 테스트와 같은 소수결·OX·소수결 부활전·네 구역 객관식·주관식이며 모두 15초다. 봇은 기존 사인/코사인 이동 패턴을 사용하고 주관식에도 답한다. 사람이 없으면 이동 계산을 쉬며, 새로운 소켓 연결이나 디스크 통계 기록은 생성하지 않는다. 실제 두 사용자에게는 기존 델타 월드 방송을 사용한다.

이는 **게임 화면과 게임 진행을 보는 서버 내부 NPC 방**이다. 48개의 외부 WebSocket 연결을 만들어 회선 부하를 재현하는 방은 아니다. 실제 50명·100명 통신 부하는 `network-load-test.cjs`로 별도 검증한다. 로컬의 기존 `test:50` 봇 실행기는 변경하지 않는다.

일반 `npm start`는 환경 변수가 없으면 이 방을 만들지 않는다. 자동 테스트는 단일 생성, 정원, 방장 이전, 관전자 위치, 쉬는 동작, 답안 제출을 검증한다.
