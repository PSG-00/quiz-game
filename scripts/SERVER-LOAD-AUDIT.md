# 서버 부하 점검 — 2026-10-25

성능 비교 HTML·스냅샷·CPU/GPU 진단·FPS 수집과 표시가 실행 경로에 남아 있지 않은지 확인했다. LOD, 인스턴싱, 관전석 크기 보간은 브라우저 렌더링 기능이며 새로운 서버 타이머나 메시지를 추가하지 않는다.

## 발견 및 정리

- 일반 클라이언트는 정지 중에도 약 55ms 간격으로 동일 MOVE를 전송했다. 서버의 소수점 둘째 자리 좌표와 역할을 비교해 변경 시에만 전송하도록 수정했다. 입장·로비 복귀 때 전송 키를 초기화한다. 실제 이동의 전송 간격은 유지한다.
- 게임 규칙 창의 FPS 측정 문구와 매초 FPS 계산을 제거했다. 기존 FPS 수집은 클라이언트 계산이었으며 서버로 보고하지 않았다.
- `scripts/load-test-room.cjs`로 실행 중인 테스트 봇 49명은 약 100ms 간격으로 각자 MOVE를 전송한다. 초당 약 490개 입력이며, 66ms 월드 방송까지 포함해 점검 당시 49개 로컬 소켓의 수신 합계가 약 4.0~4.2MB/s였다. 이는 폰 한 대의 수신량이나 인터넷 터널 대역폭 수치가 아니다. 테스트용 통계 JSON도 5초마다 기록한다. 사용자가 **테스트 봇 유지**를 선택했으므로 중지하거나 방을 재시작하지 않았다. 일반 실행 `npm start`에는 봇 생성과 통계 파일 기록이 없다.

## 유지한 정상 동작

서버 월드 방송은 단일 66ms 루프에서 참가자가 있는 방만 처리한다. 연결 확인은 단일 15초 루프이며, 문제·정답·휴식 타이머는 게임 진행에 필요하다. 저장 퀴즈는 초기화/저장 요청 때 처리하며 성능 측정용 주기 저장은 일반 서버에 없다. 삭제한 비교용 서비스 경로나 자동 벤치마크 루프는 없다.

PC 및 PC GPU의 모바일 화면 재현에서 생존자·유령·부활전 역할 이동·저사양 모드 전환에 75% 크기와 100% 복원을 확인했다. 정지 후 추가 MOVE 0건, 이동 중 전송 유지, 브라우저 오류 0건을 확인했다. GPU/CPU 전체 사용률이나 실제 폰 FPS 개선을 측정한 결과는 아니다.
