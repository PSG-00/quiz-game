# 50명 정원 부하 테스트

`npm run test:50`으로 현재 코드를 사용하는 3105 서버와 봇 49명을 실행합니다. 다른 포트는 PowerShell에서 `$env:PORT='3110'; npm run test:50`처럼 지정합니다. 이미 해당 포트가 사용 중이면 기존 프로세스를 건드리지 않고 오류로 종료합니다.

방 목록의 **[테스트] 50명 방 · 이동/소수결**에 입장합니다. 처음 들어온 실제 사용자가 방장이 되므로 시작·재시작할 수 있습니다. 봇은 여섯 아바타로 계속 이동하고, 주관식/버튼 객관식에는 예시 답을 제출합니다. OX·소수결·소수결 부활전·네 구역 이동 객관식·주관식이 포함됩니다.

모든 방의 최대 인원은 **50명**입니다. 테스트 방은 **봇 49명 + 실제 사용자 1명 = 50명**으로 정원을 지킵니다. `npm start`에서는 테스트 방이나 봇이 생성되지 않습니다. 테스트 방의 게임은 저장 퀴즈 보관함에 저장하지 않습니다. 실행 중인 서버의 저장 정책은 기존 `server/index.js`와 같습니다.

49개의 실제 WebSocket 연결이 서버의 입장·이동·판정·방송 코드를 통과합니다. 동일한 WORLD_TICK 메시지를 받아도 운전 스크립트는 한 연결에서만 JSON을 해석하고 공유하여, 이 PC에서 49개 JSON 파서를 돌리는 추가 부하를 줄입니다. 이는 **49개 기기/브라우저의 실제 렌더링 성능 테스트가 아닙니다.** 브라우저 한 개에서 모든 캐릭터를 그리는 비용과 서버의 49개 연결 처리·송수신을 테스트합니다.

`artifacts/bot-load-test.json`에 PID·방 ID·접속 수·누적 입력·수신 바이트/초가 기록됩니다. 표시된 바이트는 49개 로컬 소켓 수신 합계이며 실제 인터넷 회선 처리량이 아닙니다. 터미널에서 실행했다면 Ctrl+C로 서버와 봇을 함께 종료합니다. 숨김 실행은 기록된 테스트 PID의 **명령줄이 이 스크립트인지 확인한 뒤** 그 프로세스만 종료합니다. 그러면 테스트 방도 닫힙니다.

소수결은 준비·진행 중 좌우 인원수와 소수 구역을 안내하지 않습니다. 캐릭터는 계속 보이며, 판정이 끝난 뒤 결과 화면에서 최종 좌우 인원수와 승리 구역을 공개합니다. 접속자가 화면의 캐릭터 위치를 직접 세거나 네트워크 좌표를 분석하는 것까지 막는 기능은 아닙니다.

PC·모바일 모두 `저사양 모드`를 켜면 본인만 정밀 3D로 그리고, 다른 사람은
둥근 머리와 역원뿔 몸통이 떨어진 간단한 SD로 표시합니다. 머리·몸·눈을
InstancedMesh 세 개로 그리며 사람당 264삼각형입니다. 닉네임·상태판·채팅은
유지하며 탈락자는 기존 유령으로 전환합니다. 모드를 끄면 정밀 아바타를
프레임당 최대 두 개씩 복원합니다. 생성했던 모델은 재사용하고, 표시하지
않는 모델은 장면에서 분리하여 숨겨진 뼈대의 행렬 계산도 피합니다.
기본은 꺼짐이며 설정은 해당 브라우저에 저장합니다.

모바일은 화면 주사율에 맞춰 최대 144FPS를 허용합니다. 실제 FPS는 기기·브라우저·부하에 따라 달라지며 게임 규칙 창에서 확인할 수 있습니다.

원격 정밀 아바타에는 화면에 보이는 크기에 따라 원본·중간·낮은 단계의 LOD를 적용합니다. 본인 모델과 기존 인스턴싱·저사양 모드는 유지합니다. LOD 생성은 `node scripts/build-avatar-lod.cjs`, 검증은 `node --test tests/avatar-lod.test.cjs`로 실행합니다.

성능 비교용 HTML·스냅샷과 CPU/GPU 진단은 제거했습니다. 50명 정원 테스트는 기존 게임의 실제 방에서 진행합니다.
