# 2026-10-25 자동 비교 기록

## 사용자 실기기 결과 및 채택 결정

사용자가 Cloudflare Quick Tunnel을 통해 직접 비교한 결과:

| 버전 | 실제 폰 | 실제 노트북 |
| --- | ---: | ---: |
| 기준 WebGL | 30~33 FPS | 약 90 FPS |
| WebGL + LOD | 50~52 FPS | 약 110 FPS |
| WebGPU + LOD | 30~33 FPS | 약 90 FPS |

WebGPU는 로딩이 매우 느리고 시간 경과 후 프레임 하락도 관찰됐다는 사용자 보고로 채택하지 않는다. 이 관찰만으로 메모리 누수 등 원인은 확정할 수 없다. **기본 실행 버전은 `codex/perf-lod`로 전환**한다. 기존 기준 버전과 WebGPU는 비교용 브랜치/페이지로 보존한다. 3105 서버 및 기존 방을 재시작하지 않고 정적 클라이언트만 전환했으므로 이미 열린 게임 화면에는 새로고침이 필요하다.

아래 자동 측정값은 사용자 실기기 결과와 구분해 보존한다.

현재 PC의 실제 Chrome GPU 렌더링, headless, 1280×800, DPR 1. 저사양 모드 OFF, 원격 캐릭터 100 + 본인, 같은 배치/이동, 모델 준비 후 10초 예열, 각 30초. 동시에 다른 GPU 테스트를 실행하지 않았다. 실제 노트북 화면 표시 주사율 측정이나 실제 폰 GPU 측정과 구분한다.

| 버전 | 평균 FPS | P95 프레임 간격 | 마지막 프레임 삼각형 | 마지막 프레임 draws |
| --- | ---: | ---: | ---: | ---: |
| 기준 WebGL | 44.8 | 42.1ms | 10,214,087 | 88 |
| WebGL + LOD | 80.6 | 27.8ms | 3,493,825 | 116 |
| WebGPU + LOD | 64.8 | 34.5ms | 3,609,994 | 126 |

각 버전의 브라우저 오류 0. 원본 JSON: `artifacts/perf-comparison-30s.json`. 기준/LOD/WebGPU 단기 정순·역순도 실행했으며 FPS 편차가 컸다. 따라서 이 한 번의 측정값을 모든 기기의 성능으로 일반화하지 않는다. WebGPU가 항상 우세하다는 결론도 성립하지 않는다. LOD는 실제 삼각형 처리를 약 66% 줄였으며 단계가 섞이면 draws는 늘어난다.

390×844 DPR 2 모바일 레이아웃은 PC GPU로 별도 확인했다. 실제 폰 성능 수치가 아니므로 위 표와 합치지 않는다. 실제 폰에서는 기존 ngrok HTTPS 주소의 `/performance-compare.html`에서 각 버전을 한 화면씩 30초 측정하고 JSON을 저장해야 한다. 미지원 안내가 나오면 WebGPU 측정은 불가하다.

기능 검증: 실제 WebGPU에서 각자 다른 애니메이션 위상, 저사양 모드 ON/OFF, 유령 5명/부활, 아바타 선택 미리보기 통과. WebGPU 미지원 시 WebGL + LOD 안내 확인. 게임 로직 + LOD 원본 해시/인덱스 범위 + 구/신 로더 연결 테스트 총 98개 통과. 원본 6개 모델과 저장 퀴즈 데이터는 유지했다. 3105의 봇 100명 방도 유지했다.


## 추가 LOD 실험의 실제 폰 재검증

사용자는 A(기존 LOD), B(추가 최적화), C(선택 고화질) 사이에 큰 차이가 없고, A도 앞선 측정보다 약 10% 낮아진 느낌이라고 보고했다. 정확한 새 FPS 수치는 제공되지 않았다. PC 자동 측정의 개선 경향을 실기기 성능 향상으로 인정하지 않는다. 추가 패치는 채택을 보류하고 기본 클라이언트를 codex/perf-lod로 복원했다. codex/perf-lod-plus 및 B/C 정적 스냅샷은 비교용으로 보존한다.

A 스냅샷의 app.js, avatarLOD.js, instancedAvatars.js, sceneAntialias.js, style.css는 이전 LOD 브랜치와 동일했다(일부 줄바꿈 차이 제외). 공통 측정 도구는 추가 실험 중 변경됐으므로 A를 이전 브랜치에서 다시 내보내 원래 측정 도구까지 복원했다. 이것이 약 10% 하락의 원인이라는 근거는 없으며, 발열·메모리 누수·GPU 병목도 확정하지 않는다. 3105 서버와 100봇 방은 재시작하지 않았다.
