# 불투명한 애니풍 머리 — v5

최근 첨부한 애니풍 참고 이미지에 맞춰 시스루/가는 머리카락 표현을 제거한 버전입니다.

- 가발 내부의 개별 머리카락 곡선 오브젝트를 전부 제거
- 앞머리는 다섯 개의 넓고 둥근 입체 메시로 신규 제작
- 앞머리가 눈썹 가까이까지 내려와 이마의 빈 공간을 덮음
- 정수리 위 볼륨을 낮추고, 불투명한 두상 메시와 연결
- 세 가지 색을 기준으로 명암을 조절한 애니풍 표현
- 기존 원본 머리는 재활용하지 않았으며, 귀 앞 옆머리는 없음
- 뒤로 묶은 포니테일과 검은 리본 유지

`liv-solid-anime-wig-v5.blend`는 편집 가능한 Blender 원본입니다. 정면/사선/전신 렌더가 함께 생성됩니다. 제작 스크립트는 `../liv/build_liv_v5_anime_hair.py`입니다.

승인 후 `../liv/export_liv_v5_game.py`로 재질을 베이크해 프로젝트 루트의 `client/assets/models/liv-anime-v5-walk.glb`에 게임용 모델을 생성했습니다. 게임의 리브 선택에 이 모델이 연결되어 있습니다. 7개의 메시, 공유 텍스처, 팔다리·무릎·발목·팔꿈치 관절로 구성되어 걷기와 개별 유령 효과를 지원합니다. 이전 `liv-anime-v5.glb`는 정적 팔다리 피벗을 사용했던 이전 파일입니다.
