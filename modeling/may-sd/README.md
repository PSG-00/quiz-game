# 메이 SD v1

사용자가 제공한 메이 사진 두 장을 바탕으로 기존 리브와 같은 SD 좌표 변형과 관절 구조로 제작했습니다.

- 갈색 턱선 단발: 새로 만든 독립 가발과 일곱 개의 불투명 애니풍 앞머리 덩어리. 얼굴과 귀 앞 공간 확보.
- 남색·아이보리 줄무늬 끈 크롭 상의와 간략화한 방패/별 패치.
- 베이지 와이드 팬츠: 좌우 바지통과 골반/고무줄 허리밴드를 각각 입체 제작. 양쪽 바지통은 무릎·발목·다리 관절에 연결합니다.
- 실버 링 귀걸이, 얇은 목걸이와 팔찌. 사진에 보이지 않는 신발은 남색/아이보리 운동화로 보완했습니다.
- 얼굴과 손·신발의 기본 토폴로지는 기존에 사용자가 제공한 애니 모델 기반을 재사용합니다. 머리·상의·바지·맨팔·장신구는 이번 참고 의상에 맞춰 제작했습니다.
- 얼굴은 별도 2048 UV 아틀라스에 베이크하고, 전체 약 3등신대 비율로 변형합니다.

원본 의상 `may-outfit-source.blend`, 게임용 편집 원본 `may-sd-v1.blend`, 실제 모델 `../../client/assets/models/may-sd-v1-walk.glb`.
재생성: 프로젝트 루트에서 Blender로 `modeling/may-sd/build_may_sd.py` 실행. 승인된 리브 원본 및 공통 SD 익스포터를 입력으로 사용합니다.

검증: 기존 테스트 56개 통과. Chrome PC/모바일에서 메이 선택·입장, 4방향 이동, 카메라 유지, 관절 복제 독립성, 유령 재질/자세, 정지 후 복귀를 확인했습니다. `may-sd-v1-full.png`는 실제 게임 GLB의 정면 렌더입니다.

현재 적용 버전과 공통 체형·선택 이름은 `../CHARACTER_STYLE.md`를 참조하세요. 기존 파일은 이전 버전 보존용입니다.
