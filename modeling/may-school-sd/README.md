# 메이 · 스쿨룩 SD v1

사용자가 제공한 두 무대 스크린샷을 참고한 별도 의상 버전입니다. 기존 메이 와이드 팬츠 아바타 ID `may`는 유지하고 `may-school`을 추가했습니다.

- 애쉬 브라운 단발과 살짝 바깥으로 꺾인 끝. 기존 메이의 독립된 가발을 재사용하고 색·끝 실루엣을 변경합니다.
- 회보라색 오버핏 브이넥 니트, 밝은 블루 셔츠의 깃과 밑단, 줄무늬 넥타이.
- 두 겹 베이지 주름치마. 실제 접힌 면과 안쪽 그림자 색을 사용합니다.
- 접힌 흰 레그워머와 검정 로퍼, 작은 링 귀걸이와 무대용 헤드셋.
- 리브·메이와 같은 약 3등신대 SD 변형, 걷기·회전·유령 표시 방식.

파일: 의상 원본 `may-school-outfit-source.blend`, 게임용 편집 원본 `may-school-sd-v1.blend`, 정면 게임 렌더 `may-school-sd-v1-full.png`, 실제 GLB `../../client/assets/models/may-school-sd-v1-walk.glb`.
재생성: 프로젝트 루트에서 Blender로 `modeling/may-school-sd/build_may_school_sd.py` 실행. 기존 메이 의상 원본·리브 다리 메시·공통 SD 익스포터를 사용합니다.

텍스처: 얼굴 2048, 몸통/다리 1024, 팔 512, 가발 1024. 다리는 여백 32px의 별도 아틀라스를 사용합니다. 원본에 여러 UV가 있으므로 모든 베이크 결과는 게임 아틀라스 UV 하나만 남깁니다. UV 삭제는 이름 목록으로 처리하여 Blender RNA 인덱스 이동으로 잘못된 UV가 남지 않게 합니다. 로퍼와 겹치던 원본 발은 제거합니다.

검증: 테스트 57개 통과. 실제 Chrome에서 PC·모바일 스쿨룩 선택, 기존 메이 보존, 입장 모델 버전, 유령 재질, 개별 관절 독립성, 4방향 걷기와 고정 카메라, 정지 복귀, 단일 UV 내보내기를 확인했습니다. 최종 정면/옆/뒤 렌더에서 의상과 신발 색을 확인했습니다.

현재 적용 버전과 공통 체형·선택 이름은 `../CHARACTER_STYLE.md`를 참조하세요. 기존 파일은 이전 버전 보존용입니다.
