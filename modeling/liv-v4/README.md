# 머리 전체 신규 제작 — 독립 가발 시안

v2 모델을 열어 기존 원본 머리 메시, 덧붙였던 앞머리, 기존 리본 관련 오브젝트를 모두 제거했습니다. 원본 머리의 형상이나 옆머리를 재활용하지 않았습니다. 얼굴과 의상은 v2를 유지합니다.

새 머리는 `Liv — independent complete wig` 컬렉션 아래 `Liv_Wig_Complete_New_Model` 부모 오브젝트에 묶여 있으며, 가발처럼 전체를 한꺼번에 숨기거나 분리할 수 있습니다.

- 신규 두상 맞춤 스칼프: 앞머리 경계는 부드럽게 페이드
- 뒤로 빗어 모은 두피 머리카락
- 이마가 비치는 가는 시스루뱅
- 앞머리는 얼굴 표면을 조회해 곡면에 맞추어 배치
- 목 뒤로 내려오는 신규 포니테일
- 포니테일에 묶은 검은 리본
- 귀 앞과 볼 옆으로 내려오는 옆머리 없음

`liv-complete-new-wig-v4.blend`는 텍스처가 내장된 Blender 원본입니다. 정면/사선/뒷모습/전신 렌더를 함께 생성합니다. 재생성 스크립트는 `../liv/build_liv_v4_wig.py`입니다.

현재는 게임 적용 전 검토용 렌더 모델입니다. 가는 머리카락은 Blender 곡선으로 제작되어 있으며, 게임에 적용하려면 헤어 카드/메시 변환과 최적화가 필요합니다.
