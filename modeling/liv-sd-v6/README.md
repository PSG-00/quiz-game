# 리브 SD v6

승인된 v5 가발과 의상을 유지하면서 게임에서 얼굴을 읽기 쉬운 약 3등신대 SD 비율로 조정했습니다.

- 머리 가로 폭 1.46배, 머리 높이 1.4배. 몸 폭 1.12배, 다리 높이 0.6배, 몸통 높이 0.68배, 목 높이 0.45배. 게임에서는 전체 키 2.95로 정규화합니다.
- 얼굴의 중복 위치 정점을 용접하되 원본 UV는 보존하여 참조 텍스처를 읽습니다. 별도 FaceGameAtlas에 2048 해상도, 32px 여백으로 베이크한 뒤 게임용 UV만 내보냅니다.
- 비율 변형을 베이크와 가중치 생성 뒤에 메시와 모든 뼈에 동일하게 적용합니다. 기존 걷기·회전·유령 동작을 유지합니다.
- 원본 승인 v5 파일은 보존합니다. SD 원본 `liv-sd-v6.blend`, 실제 게임 모델 `../../client/assets/models/liv-sd-v6-walk.glb`.
- 재생성: 프로젝트 루트에서 Blender 백그라운드 실행으로 `modeling/liv/export_liv_sd_v6_game.py` 실행.

검증: 기존 56개 테스트 통과. Chrome에서 모바일·PC 이동 방향, 고정 카메라, 정지 후 자세 복귀, 개별 스켈레톤과 유령 재질, 전신/얼굴 렌더를 확인했습니다.

현재 적용 버전과 공통 체형·선택 이름은 `../CHARACTER_STYLE.md`를 참조하세요. 기존 파일은 이전 버전 보존용입니다.
