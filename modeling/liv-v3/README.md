# 시스루뱅 수정 시안

사용자가 제공한 시스루뱅 참고 이미지를 기준으로 v2 모델의 앞머리만 수정했습니다.

- 원본 머리의 두꺼운 중앙 앞머리 면과 기존 직선 형태의 가는 앞머리를 제거
- 정수리에서 이마를 따라 내려오는 얇고 곡선인 머리 다발 33개 제작
- 뿌리에서 끝으로 갈수록 폭이 줄어들고, 이마가 드러나도록 간격 조정
- 끝 길이, 가르마 흐름, 좌우 휘어짐, 갈색 명암에 작은 차이 적용
- 두상 표면을 조회해 앞머리가 얼굴을 뚫지 않도록 배치

`liv-see-through-bangs-v3.blend`는 텍스처가 내장된 Blender 원본입니다. `liv-v3-face.png`는 정면 얼굴, `liv-v3-face-angle.png`는 사선 얼굴, `liv-v3-full.png`는 전신 렌더입니다. 재생성 스크립트는 `../liv/build_liv_v3_bangs.py`입니다. 현재 게임 파일 교체 전 검토용 모델입니다.
