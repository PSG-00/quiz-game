# 목표 인원 미달 시 준우승 추첨

마지막 판정 뒤 생존자가 1명 이상이고 목표 인원보다 적으면, 생존자 모두는 우승 확정이다. 부족한 당첨 자리는 그 판정 직전 생존자 중 이번에 탈락한 사람들로만 추첨한다. 이전 라운드 유령·중도 관전자·이미 퇴장했거나 참가 자격을 잃은 사람은 후보가 아니다. 우승 확정자는 다시 추첨하지 않는다.

예: 목표 2명, 마지막 판정 직전 생존자 5명 중 1명 정답 → 정답자 1명 우승 확정, 나머지 4명 중 1명 준우승 추첨. 서버는 4.2초 LOTTERY 상태에서 후보 이름을 순환 표시하고 ENDED에서 우승·준우승을 구분해 발표한다. 준우승 선정은 부활 판정이 아니며 탈락자의 생존 상태를 바꾸지 않는다.

후보가 모자라면 실제 후보 수까지만 선정한다. 목표와 생존자가 같으면 전원 당첨으로 바로 종료한다. 전원 오답일 때의 직전 생존자 기준 추첨과 목표 초과 시 추첨 규칙은 그대로다.

검증: `tests/runner-up.test.cjs`, `scripts/audit-connection-recovery.cjs`.
