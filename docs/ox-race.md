# OX 레이스

문제 편집기의 `OX 레이스`에서 1~10개 OX 문항과 정답을 설정한다. 각 문항은 100자 이내이며, 전체 제한시간은 5~300초(기본 120초)다. 저장·코드 불러오기에도 포함된다.

참가자는 같은 T자 맵을 사용한다. 출발점에서 교차로로 이동한 뒤 왼쪽 O, 오른쪽 X 끝에 닿으면 서버가 판정한다. 정답이면 다음 개인 문항, 오답이면 같은 문항으로 출발점에 돌아온다. 문항 순서는 참가자마다 섞인다. PC 방향키/WASD, 모바일 조이스틱, 바닥 터치 이동을 지원한다.

통과 정원은 해당 라운드 시작 시 참가 인원 `max(1, floor(N / 2))`로 고정한다. 25명은 12명, 50명은 25명, 단독 테스트는 1명이다. 참가자가 0명이면 정원도 0명이다. 서버가 마지막 정답 문 통과를 처리한 순서로 완주자를 기록하고, 정원이 차면 즉시 라운드를 마감한다. 중도 입장과 퇴장으로 정원을 다시 계산하지 않는다.

제한시간에 정원이 덜 찼다면 실제 완주자만 통과한다. 완주자가 0명이면 탈락 없이 같은 레이스를 다시 시작한다. 패자부활전에서는 참가 자격이 있는 유령만 달리고 동일한 규칙으로 부활한다. 일반 게임의 최종 당첨 목표와 추첨 규칙은 그대로 적용한다.

정답과 전체 문항 순서는 서버에만 보관한다. 클라이언트는 현재 개인 문항·진행도·완주 순위만 받는다. 이동 속도, 벽 충돌, 문 통과, 라운드 식별자와 마감은 서버가 검증한다. 짧은 연결 끊김 후 복귀 시 개인 진행도를 유지한다.

검증: `node --test tests/race-round.test.cjs`, `npm test`, `node scripts/audit-race.cjs`. 브라우저 검증은 격리 포트 3146을 사용하며 실기기 성능 측정은 아니다.
