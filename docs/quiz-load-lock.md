# 운영 서버 퀴즈 불러오기 임시 잠금

`NODE_ENV=production`에서만 관리자 비밀번호를 요구한다. 로컬 개발 서버는 기존대로 사용한다. 명시적 `OX_QUIZ_LOAD_LOCK=1`은 검증용 강제 활성화, `OX_QUIZ_LOAD_LOCK=0`은 임시 잠금 해제다.

`퀴즈 불러오기`를 누르면 비밀번호 입력 창을 연다. 인증은 현재 WebSocket 연결에서 15분 유효하고, 창을 다시 열 때 다시 비밀번호를 묻는다. 비밀번호는 브라우저 저장소에 보관하지 않고 전송 직후 입력칸을 비운다. 연결이 끊기면 인증도 해제한다.

서버는 공개 목록 조회, 내 보관함 불러오기, 코드 불러오기를 인증 없이 거부한다. 예전 초안 복구 HTTP 경로도 잠금 중에는 내용을 반환하지 않는다. 퀴즈 작성·저장과 게임 참여는 기존대로 동작한다.

서버의 `quizLoadPassword.json`에는 무작위 salt와 scrypt 검증 해시만 보관한다. 원문 비밀번호는 클라이언트 파일·서버 설정·로그에 저장하지 않는다. 비밀번호 시도는 주소별 1분 5회, 동시 검증은 4개로 제한한다. 설정 파일이 없으면 잠금은 열린 상태로 바뀌지 않고 불러오기를 거부한다.

검증: `npm test`, `QUIZ_TEST_PASSWORD` 환경변수를 지정한 `node scripts/audit-quiz-load-lock.cjs`. 후자는 격리된 3148 포트를 사용하고 실제 저장 퀴즈를 변경하지 않는다.
